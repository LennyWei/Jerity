# Jerity menu recordings

Add these four MP3 files here:

- `home-1.mp3` and `home-2.mp3`: landing page greetings.
- `lobby-1.mp3` and `lobby-2.mp3`: lobby greetings.

The two clips alternate, with a 25-second pause after playback. Missing clips
stay silent. Browser autoplay rules require a tap or key press on the first page.
The music-note button mutes Jerity. The files are copied by Vite during builds.
